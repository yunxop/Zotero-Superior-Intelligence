# 2.0.0 更新说明

本版本重点：免费开放 PDF 对话、文献自动标记和科研语料/证据提取，并新增完整的主题管理工作流。

## 科研写作知识库

- 批量读取选择的论文、父分类及全部子分类、当前文献库；重复归类去重。
- 关键词 + 可选 Voyage 语义筛选，提取英文原句、写作技巧与科学证据。
- 保留来源段落、DOI、页码、PDF 定位；支持审核、复制和导出。
- SQLite 本地存储、Markdown 镜像、Agent JSONL 和已通过记录的微调 JSONL。

## 主题管理

- 固定主题 ID，旧数据自动迁移并保留原始记录备份。
- 搜索、分页、置顶、归档、三级文件夹路径和标签。
- 名称与提取指令分离；重命名、合并与别名。
- 记录关联、移动和从本主题移除；主题与记录回收站。
- 提取历史保留当时的指令、论文队列、模型与结果。

## 安装与验证

安装包：`zotero-superior-intelligence-2.0.0.xpi`，支持 Zotero 10.0.x。

24 个自动化测试脚本已通过；真实 Zotero 升级和真实服务 API 联调尚未实测。迁移后的数据库不建议降级到旧版继续写入；升级前可备份 Zotero 数据目录。

插件免费开源，第三方 LLM、Voyage 或解析服务可能收费。完整操作、存储位置及限制见 [使用指南](writing-knowledge.md)。
