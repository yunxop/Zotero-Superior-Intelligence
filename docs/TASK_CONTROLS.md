# 设置保存、任务暂停与续跑

思考模式是全局偏好，调整后立即保存。文献总结、表格总结、高亮、PDF 对话和文献库对话分别记住自己的 Token 上限；工作台同时记住最后选择的任务类型。关闭窗口或重启 Zotero 后仍保留。

## 对话和笔记

同一轮 PDF 对话再次保存会更新关联笔记。清空对话会开始新对话，保留已经保存的旧笔记；新对话另建笔记。保存时使用快照并阻止重复点击，清空对话会取消尚在生成的回答。

公式支持 `$…$`、`$$…$$`、`\(...\)` 与 `\[...\]`。界面使用内置 KaTeX，无须联网；笔记保存为 Zotero 原生可编辑公式。代码块保持原文，错误公式保留 TeX 以便修正。

## 工作台暂停与续跑

任务执行时，可在弹窗或工作台点击“暂停任务”。关闭工作台窗口也会暂停。单篇任务可在历史记录点击“继续任务”；批处理可点击“继续批处理”，已完成文献不会重复保存。

完成的长文分析段、高亮分组、文献库综述批次和证据整合阶段保存在 Zotero 数据目录的 `si-task-checkpoints-v1.json`，最多 40 项、8 MiB、保留 30 天。检查点不保存 API 密钥或原始全文。修改 PDF 正文、提示词、模型或生成设置会重新分析，避免使用不匹配结果。

续跑复用已经完整完成的阶段。暂停时正在生成的请求需重新执行；MinerU 的远端解析任务 ID 未保存，解析阶段中断后会重新解析。客户端取消不等同于删除服务端任务。

## 文献库追问

最近两轮问题、回答短摘要和来源关联参与追问。每次请求从当前资料范围重新读取来源并重新编号，历史摘要不当作事实证据。范围变化或点击“清空对话”会开始新话题。

文献库范围综述停止后，再次使用相同范围、问题和模型设置运行，即可复用已完成的批次及证据合并阶段；重启 Zotero 后也可继续。最后的综合回答会重新生成。

## 验证

`npm run test:all` 包含核心、设置重开、保存保护、分段恢复、公式及浏览器界面测试。首次开发环境准备：`npm install`，随后 `npx playwright install chromium`。系统 Chrome 可用时也可通过 `CHROME_PATH` 指定。CI 安装 Chromium 及系统依赖后执行完整测试。
