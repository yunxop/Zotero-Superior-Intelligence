# 设置保存、任务暂停与续跑

思考模式是全局偏好，调整后立即保存。文献总结、表格总结、高亮、PDF 对话和文献库对话分别记住自己的 Token 上限；工作台同时记住最后选择的任务类型。关闭窗口或重启 Zotero 后仍保留。

## 总结角度与提示词

选择“文献总结”后，可通过“总结角度”切换：

- 综合阅读：保留原有通用模板与用户已保存的自定义内容。
- 研究问题与机制：梳理问题、假设、机制与证据链，区分相关与因果。
- 方法与复现：拆解样本、数据、流程、参数与评价指标，列出复现缺口。
- 批判评价与启发：评价证据强度、偏倚和适用范围，提出明确标注的后续研究建议。

各角度可独立编辑，点击“保存提示词”后跨窗口、跨重启保留；“恢复预设提示词”只恢复当前角度。切换角度或总结类型会保留本窗口尚未保存的草稿。运行任务使用启动时的提示词快照，续跑使用历史任务的原始提示词，不会覆盖当前保存的模板。表格总结仍使用独立提示词，高亮继续使用既定标记规则。

新笔记标题包含总结角度，例如“文献总结 · 方法与复现 · 论文题目”，正文开头也注明角度。标题取自任务启动时的选择；已有笔记及缓存复用的原笔记不自动改名。

## 对话和笔记

同一轮 PDF 对话再次保存会更新关联笔记。清空对话会开始新对话，保留已经保存的旧笔记；新对话另建笔记。保存时使用快照并阻止重复点击，清空对话会取消尚在生成的回答。

公式支持 `$…$`、`$$…$$`、`\(...\)` 与 `\[...\]`。界面使用内置 KaTeX，无须联网；笔记保存为 Zotero 原生可编辑公式。代码块保持原文，错误公式保留 TeX 以便修正。

## 工作台暂停与续跑

文献总结、表格总结、高亮、批处理和直接提取由插件后台执行。关闭进度提示或整个 SI 工作台窗口后继续运行并保存结果；重新打开会恢复当前任务的文献选择、进度与暂停按钮，不会重复启动或重复保存。批处理会继续处理剩余文献。

从 1.1.3 起，重新打开工作台只在页面内恢复任务状态，不自动弹出旧进度或完成提示。已结束任务不会替换当前文献选择和总结角度。主动开始新任务时显示进度弹窗；关闭后任务完成也不会再弹出，可随时点击“查看任务详情”。

需要停止时，在弹窗或工作台点击“暂停任务”。退出 Zotero、停用或重载插件也会中断执行。单篇任务可在历史记录点击“继续任务”；批处理可点击“继续批处理”，已完成文献不会重复保存。直接提取再次启动时会重新申请解析。

同一时刻只能运行一个工作台任务。当前 Zotero 会话保留最近一次任务的结果预览；批处理预览最多保留最近 50 篇，并限制正文预览的内存占用。完整结果保存在文献笔记或 PDF 高亮中，直接提取是否自动保存仍遵循设置。退出 Zotero 后任务不会继续运行，重启后可通过历史记录或保留队列续跑。

完成的长文分析段、高亮分组、文献库综述批次和证据整合阶段保存在 Zotero 数据目录的 `si-task-checkpoints-v1.json`，最多 40 项、8 MiB、保留 30 天。检查点不保存 API 密钥或原始全文。修改 PDF 正文、提示词、模型或生成设置会重新分析，避免使用不匹配结果。

续跑复用已经完整完成的阶段。暂停时正在生成的请求需重新执行；MinerU 的远端解析任务 ID 未保存，解析阶段中断后会重新解析。客户端取消不等同于删除服务端任务。

## 文献库追问

最近两轮问题、回答短摘要和来源关联参与追问。每次请求从当前资料范围重新读取来源并重新编号，历史摘要不当作事实证据。范围变化或点击“清空对话”会开始新话题。

文献库范围综述停止后，再次使用相同范围、问题和模型设置运行，即可复用已完成的批次及证据合并阶段；重启 Zotero 后也可继续。最后的综合回答会重新生成。

## 1.1.2 稳定性与界面更新

本版本包含本地 1.1.1 修订中的修复，并将工作台任务执行与窗口生命周期分离。完整说明见 [1.1.2 更新说明](RELEASE_1.1.2.md)。

- 文献列表中明确选择某个 PDF 时，处理该附件；同时选择父文献与其 PDF 时以所选 PDF 为准。同一文献的多个 PDF 可分别处理，结果笔记仍归属父文献。工作台显示附件文件名，历史续跑保留附件 ID。
- 模型流式回答必须有有效完成状态。提前结束、流内错误及损坏响应不会保存为完整结果，也不会写入完成缓存。旧版本总结与综述缓存会失效并重新生成，已有笔记保留。
- MinerU 单次请求（含读取响应正文）最长 120 秒；Agent 总流程最长 10 分钟，精准模式最长 15 分钟。直接提取可通过工作台暂停，关闭工作台继续等待，退出 Zotero 或停用插件会取消等待。重新提取仍会重新申请服务端任务。
- 工作台模型进度、阅读器回答及文献库流式文本按 200 毫秒合并更新。任务结束立即显示最终状态；关闭工作台只解绑界面订阅，后台继续记录进度。任务历史复用已有行，阅读器仅在用户位于底部附近时跟随新文本。
- 当前问题命中的资料优先进入模型上下文，旧对话资料限额补充；无命中的追问仍保留有限历史依据。支持“锌”“铜”等单字中文检索。

## 回归测试

`npm run test:all` 包含核心、设置重开、保存保护、分段恢复、后台任务关闭与重连、公式及浏览器界面测试。首次开发环境准备：`npm install`，随后 `npx playwright install chromium`。系统 Chrome 可用时也可通过 `CHROME_PATH` 指定。CI 安装 Chromium 及系统依赖后执行完整测试。
