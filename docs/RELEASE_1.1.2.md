# 1.1.2 更新说明

本版本汇总本地 1.1.1 修订中的修复和工作台后台任务改动。目标安装包为 `zotero-superior-intelligence-1.1.2.xpi`，支持范围为 Zotero 10.0.x；是否已发布以 [GitHub Releases](https://github.com/yunxop/Zotero-Superior-Intelligence/releases) 中的实际附件为准。

## 工作台关闭后继续执行

文献总结、表格总结、高亮、批处理和正文提取由插件后台运行。关闭进度弹窗或整个 SI 工作台后，任务继续处理并保存结果；重新打开可恢复当前选择、进度和暂停按钮，不会重复启动任务。直接提取是否自动保存仍遵循用户设置。

需要停止时点击“暂停任务”。退出 Zotero、停用或重载插件仍会中断执行；已完成阶段和剩余批处理队列可用于续跑。最近一次结果预览保留在当前会话中，批处理最多保留最近 50 篇的预览，完整结果位于文献笔记或 PDF 高亮中。

## 稳定性和界面性能

- 流式回答必须包含有效完成状态；提前断流、错误帧和损坏响应不会写入完整结果缓存。达到输出上限的回答保留不完整标记。旧版不可靠的总结与综述缓存失效后重新生成，已有笔记保留。
- 明确选择 PDF 附件时使用所选文件；父文献与同一 PDF 重复选择只处理一次，同一文献的不同 PDF 可分别处理，历史续跑保留附件 ID。
- MinerU 请求和响应正文读取加入超时与取消处理：单次请求最长 120 秒，Agent 总流程最长 10 分钟，精准模式最长 15 分钟。
- 工作台、阅读器和文献库的高频流式更新按 200 毫秒合并，完成时立即刷新；任务历史复用已有行，阅读器尊重用户手动滚动的位置。
- 文献库检索支持单字中文关键词，当前问题命中的资料优先进入上下文，历史资料只作限额补充。
- 源码仓库、安装包更新地址和项目链接统一为 `yunxop/Zotero-Superior-Intelligence`。

## 验证范围

回归套件包含 19 个测试脚本，覆盖模拟 Zotero 环境中的后台执行、关闭与重连、主动暂停、批处理继续、保存去重、网络超时和流式响应完整性；文献库界面使用 Playwright 在真实无头浏览器中验证。尚未完成真实 Zotero 客户端与真实模型、MinerU API 的联调验证。
