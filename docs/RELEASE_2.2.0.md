# Zotero Superior Intelligence 2.2.0

本次更新重点改善双栏批注 HTML 的生成完整性、任务恢复与离线阅读，兼容 Zotero 10.0.x。

## HTML 生成与任务恢复

- 没有标准章节标题的论文以“正文”继续分析；修复完整大写英文句子被误判为无需翻译的文字片段。
- 正文分组、总览整理阶段和最终总览支持检查点恢复。失败或暂停后，在「文献任务 → 历史任务」点击「继续任务」，可复用仍有效的已完成结果。
- 续跑核对原文、提示词、模型及生成设置，避免复用不同任务的结果；取消后的迟到响应不会进入缓存。
- 历史任务保留实际处理的 PDF，完成后可直接打开 HTML。相同配置复用已有可用附件；文件缺失或归属变化时重新保存。

## 来源与阅读排版

- 为可定位的段落保留实际 PDF 页码和页标，提供个人库或群组库的原文跳转；跨页段落保留多个来源页。
- HTML 显示翻译范围、仅保留原文的内容及原因、生成时间和模型名。缺少页码的 OCR 内容标注“页码未定位”。
- 保留解析结果中的 Markdown/HTML 表格、合并单元格和额外数据列；窄屏下宽表格可独立横向滚动。
- 原文、译文及表格中的 TeX 公式使用离线 KaTeX 排版，所需字体内嵌；不支持的公式保留原式。
- 恢复明确的软连字符；普通断词仅在原文已有完整拼写时合并，否则保留连字符。可展开整理前的提取文本核对。

## 打印与界面修复

- 打印时完整显示参考文献等折叠内容，长段落可跨页，长表格重复表头。
- 修复用量日历重建单元格后偶发无法重新居中的问题。

## 使用范围

- 表格和公式排版依赖提取结果已有 Markdown/HTML 表格或 TeX；原生 PDF 文字提取不会自动重建复杂版面。
- 表格与独立公式保留原始内容，不要求模型重写数值。图片暂保留原始标记，需回到 PDF 查看。
- 续跑仍会读取 PDF，扫描件可能再次调用 MinerU。检查点最多保留 40 项、30 天，并受 8 MiB 总容量限制；磁盘写入失败或缓存被清理时，可能需要重新生成。

## 安装与验证

安装附件 `zotero-superior-intelligence-2.2.0.xpi`：Zotero → 工具 → 插件 → 从文件安装插件，安装后重启。

本地 27 个测试脚本通过，涵盖缓存恢复、取消、来源、离线公式、表格、界面和打印。实际打印验证了 80 行跨页表格无遗漏、参考文献不重复。自动化使用模拟模型和存储环境，不代表所有真实模型、MinerU 或 Zotero 阅读器场景均已覆盖。
