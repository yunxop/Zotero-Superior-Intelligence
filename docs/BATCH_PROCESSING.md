# 批处理文献（1.1.2）

在 Zotero 文献库按 Ctrl / Shift 多选条目或 PDF，右键打开带 SI 图标的“SI 文献助手”，或从工具菜单打开 SI。工作台显示待处理列表，可勾选、全选或取消全选。修改文献库选择后，点击“读取文献库当前选择”重新带入。

在同一个“总结类型”下拉框选择文献总结、表格总结或文献高亮标记，然后点击批量按钮。每篇分别生成笔记或原生 PDF 高亮，并独立保存历史记录、文献关联与耗时。表格总结是逐篇生成表格，不是跨文献合并对比表。

队列逐篇执行。开始后冻结本次条目 ID、模型配置及提示词；期间切换文献库选择不会改变正在执行的队列。父条目与其同一 PDF 同时选中时只处理一次；不同 PDF 附件分别处理。缺失附件、条目已删除或单篇失败都会记录结果，继续下一篇。

“暂停任务”会取消当前请求，保留已完成分段及剩余队列。关闭进度弹窗或整个工作台后，后台继续处理队列并保存结果；重新打开工作台可查看当前进度或暂停。退出 Zotero、停用或重载插件会中断任务。重启后点击“继续批处理”可复用已完成分段继续处理未完成文献。

结果区按篇折叠显示最近 50 篇的预览，列表标注完成、失败、重复跳过或未执行。完整结果保存在各篇文献中。重试时可继续未完成队列，也可重新勾选文献；已有有效检查点会复用，笔记保存有去重保护，高亮沿用已有去重规则。

验证：`node tests/batch.js` 覆盖三种操作、顺序执行、失败隔离、PDF 去重、配置快照、暂停及队列锁释放。`node tests/dashboard.js` 覆盖选择列表、全选/取消、批处理结果与停止按钮；`node tests/background_tasks.js` 验证关闭窗口后继续执行、重新连接与暂停；其余高亮、错误处理和冒烟测试同时通过。尚未在真实 Zotero 文献库中执行批处理实测。
