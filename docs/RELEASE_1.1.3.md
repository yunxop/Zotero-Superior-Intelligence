# 1.1.3 更新说明

## 重开工作台不再重复弹窗

修复恢复后台任务快照时把旧任务当成新任务弹出提示的问题。重开工作台在页面内显示进度或结果，已结束任务不覆盖当前文献选择、总结类型或总结角度。主动启动新任务仍显示进度弹窗；关闭提示后，任务完成不会强制重新打开，可点击“查看任务详情”按需查看。

## 三套新的文献总结提示词

在“文献总结”的“总结角度”下新增：

- **研究问题与机制**：研究动机、理论假设、机制证据链及因果边界。
- **方法与复现**：数据与样本、分析流程、关键参数、结果核对及复现缺口。
- **批判评价与启发**：研究优势、证据有效性、偏倚、适用范围与后续研究建议。

保留原有“综合阅读”及已保存的自定义提示词。四种角度独立保存和恢复预设；切换时保留本窗口的编辑草稿。任务使用启动时的原始提示词，单篇与批处理续跑不会覆盖用户之后编辑的模板。

所有模板要求保留原文数值和单位，区分作者发现与阅读者推断，不编造数据、页码或引文。

新生成的笔记标题采用“文献总结 · 总结角度 · 论文题目”，正文开头也记录总结角度；表格总结保留独立标题，部分结果保留“未完成”标记。单篇、批处理与续跑均使用任务启动时的角度，之后切换界面不会影响标题。已有笔记不会批量改名；命中已有完整笔记的去重缓存时仍复用原笔记。

## 验证范围

回归测试覆盖任务恢复、弹窗关闭行为、提示词迁移与独立保存、快照及续跑，并在真实无头浏览器中检查工作台交互和布局。Zotero 和模型请求使用模拟环境；未进行真实 Zotero 与付费 API 联调。
