# Zotero Superior Intelligence 2.1.0

## 双栏批注 HTML

- 从一篇英文论文生成逐段对照的阅读附件。左栏提供五色高亮原文和中文译文，右栏说明段落功能、论证角色及论证技巧或漏洞。
- 章节导航可直接跳转，页末提供从研究问题到结论的论证总览。页面在窄屏自动切换为单栏。
- 支持编辑、保存和恢复双栏批注提示词，可调整译文风格和分析重点。
- 根据 PDF 的版面位置过滤页码和重复页眉页脚。参考文献等附属内容保留在可展开的原文中，公式片段合并展示，批注集中在论文论证。
- 样式与字体内嵌于单个 HTML 文件，可在 Zotero 阅读器中打开或离线阅读。缺少文字层的 PDF 使用当前 MinerU 配置提取。

## 科研工作台

- 顶部标签页提供文献分析、文献任务、文档工具和连接配置。切换标签时，可继续查看当前任务进度并打开生成的附件。
- 工作台分析任务的默认输出上限统一为 16,384 Token。已保存的上限继续生效，实际可用上限取决于模型。

## 安装

在 Zotero 10.0.x 的「工具 → 插件」中安装 `zotero-superior-intelligence-2.1.0.xpi`。安装后在文献库选中论文，打开「SI 文献助手 → 文献分析」，选择「双栏批注 HTML」。
